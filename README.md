## Why "inevitable"?

A first thought is not a reasoned answer — it is the word that arrives before you have time to think twice. Ask anyone what pops into their head at "AI" and the honest gut answer is not "robot" or "computer" or "future". It is the feeling that this is already here and there is no going back. "Inevitable" says that in a single word: ten letters, no hedging, no explanation needed. It is strong, a little unsettling, and instantly readable — the exact shape of a first thought.

## How it works

`main.ts` (Node 22, stdlib only, no network) writes exactly one word — `inevitable`, 10 bytes, no trailing newline — to `/output/entry.txt`, after a guard that the word is 1–30 characters and contains no whitespace.

## Run it

```sh
node main.ts
```

Then check the entry:

```sh
cat /output/entry.txt   # inevitable
```
